# trent-portfolio-v4

Vite + React + Tailwind portfolio. `npm run dev` to develop, `npm run build` to build.

## Layout

- `src/` — the site
  - `pages/` one file per route (see `App.jsx`)
  - `components/` shared components (BentoCard, ProjectSplit, ...)
  - `tokens/` Kelex design tokens (`tokens.css`, `tokens.js`)
  - `lib/` helpers; `shapes.css` is generated by `npm run shapes`
- `public/` — static files served as-is
  - `icons/` favicon.ico, favicon PNGs and the Apple touch icon
  - `media/<project>/` all images, GIFs and video for a project in one folder, files named `<project>-<name>`. `dist/media` mirrors it exactly:
    - `carbon/` (IBM Carbon Library), `fedregs/` (FiscalNote Federal Regulations), `mcsp-iam/` (IBM SaaS Console), `ztc/` (IBM Zero Trust Connect)
    - `coachteach/` (Coaching and teaching), `job-hunt/`, `info/`, `fartlek/`, `kelex/`, `kelor/`
- `content/` — case-study write-ups and presentation scripts, one folder per project (Markdown)
- `scripts/` — generators for shapes and the hazard banner
- `demos/` — separate Remotion video projects (own `package.json`/git); not part of the site build
  - `hp-display-center/` HP Display Center demo
  - `kelex-stageshow/` scripts that render the Kelex component GIFs in `public/media/kelex/components/`
- Root config: `vite.config.js`, `tailwind.config.js`, `postcss.config.js`, `index.html`
